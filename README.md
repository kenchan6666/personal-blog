# Personal Portfolio

Job-seeking portfolio: Next.js frontend + FastAPI backend (Mongo/Beanie + Redis).

## Quick start

### Dependencies (Mongo + Redis)

```bash
docker compose up -d
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

See [backend/README.md](backend/README.md).
