## What to build

Owner can edit bilingual brand/Hero copy, Profile fields, public email, and ordered Links in admin. Visitors see the matching locale strings on the public homepage (wired into the existing Next shell) with no auto-translation.

## Acceptance criteria

- [ ] Owner can save zh-Hant and en fields for brand, Hero, and Profile
- [ ] Public homepage renders the active locale's Owner-authored strings
- [ ] Links appear in Owner-defined order on the public Profile surface
- [ ] Missing a locale does not invent translated text
- [ ] Unauthenticated clients cannot update these fields
