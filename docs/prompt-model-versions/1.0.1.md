# 1.0.1 — Embedding fallbacks

相對 1.0.0：本帳號 UniAPI 上 `gemini-embedding-001` 無渠道。基線改為 `text-embedding-3-small`（1536 維），並在失敗時回退其他 embedding 模型。聊天模型不變。

## 模型

| 角色 | 模型 | Provider | 環境變數 |
| --- | --- | --- | --- |
| Owner Agent chat | `gemini-2.5-flash` | UniAPI | `VIOLA_AGENT_MODEL` |
| Public Guide chat | `gemini-2.5-flash` | UniAPI | `PUBLIC_AGENT_MODEL` |
| RAG embedding | `text-embedding-3-small`，失敗則回退 | UniAPI | `AGENT_EMBEDDING_MODEL` |
