# 1.0.0 — Public Guide + Owner RAG

生效範圍：公開只讀導覽與後台 Owner Agent。運行時以 `deployment/.env` 為準。

## 模型

| 角色 | 模型 | Provider | 環境變數 |
| --- | --- | --- | --- |
| Owner Agent chat | `gemini-2.5-flash` | UniAPI | `VIOLA_AGENT_MODEL` |
| Public Guide chat | `gemini-2.5-flash` | UniAPI | `PUBLIC_AGENT_MODEL` |
| RAG embedding | `gemini-embedding-001` | UniAPI | `AGENT_EMBEDDING_MODEL` |

API base：`UNI_API_BASE=https://api.uniapi.io`（程式會正規化為 `/v1`）。
