# Visual direction: light flat liquid glass

Public and admin UI use a **light, flat, liquid-glass** system: pastel page wash, large Gaussian-blurred color orbs, translucent white panels with strong `backdrop-filter`, dark ink for type, and coral capsule CTAs. Pixel art stays an accent only. This supersedes ADR-0006 (deep purple Digicrypt hero) because a job-seeking site still needs a distinctive shell, but the dark purple high-contrast look fought readability of long-form writing and the Owner’s requested light glass language.

Keep Hero two-column layout, capsule CTAs, and restrained pixel signature. Do not add a second theme switcher in v1.

Full tokens, layout rules, and do/don't: `docs/design/VISUAL.md`.
